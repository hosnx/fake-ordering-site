# 假點餐網站

這是一個純前端示範網站，不會：
- 收集個人資料
- 真的送出訂單
- 連接付款
- 連接餐廳後台

## 使用方法

1. 解壓縮 ZIP。
2. 雙擊 `index.html`，即可在電腦瀏覽器開啟。
3. 要讓手機掃 QR Code 打開，可把整個資料夾上傳到：
   - GitHub Pages
   - Netlify
   - Vercel
4. 取得公開網址後，再用任何 QR Code 產生器建立 QR Code。

## 修改餐牌

打開 `script.js`，修改最上方 `menuItems` 內的名稱、價錢、描述和 emoji。

## 點餐流程更新
- 小食及飲品各有預設的「不用加配」選項。
- 購物車的「修改套餐」可更改加配；修改套用至該組全部份數，返回或 Esc 則取消修改。
- 確認落單會保存商品、加配、數量、備註及總額的快照，並清空購物車，避免重複提交。
- 頁首可查看已落單紀錄，只存於目前頁面的 JavaScript 記憶體，不寫入瀏覽器儲存或後台；重新載入或新開頁面即清空，不會與其他人共享。
- 成功視窗右上角可按交叉返回餐牌，「再落一張單」亦保留本次已落單紀錄。
- 彈窗支援焦點移入、Tab 循環、Esc 關閉及焦點返回。


## 飲品口味設定
- 套餐選擇飲品後，下方顯示「修改甜度／冰量」。設定頁儲存後返回加配頁，保留餐點、加配、數量及捲動位置；返回箭頭或 Esc 取消本次口味修改。
- 主頁單點飲品會先開啟設定頁，確認後才加入購物車；取消不加入。
- 甜度：正常甜、少甜、半甜、走甜；冰量：正常冰、少冰、走冰。預設正常甜、正常冰，不另收費。
- 不同口味的單點飲品分開顯示，相同飲品及口味合併數量。
- 購物車、套餐修改及本次已落單紀錄均保留並顯示口味。
